## 🎮 二、最佳游戏体验指南

为了获得最极致的“主机级”游戏体验，我们强烈推荐您这样使用 iEmulator：

1. **连接无线手柄**：在 iPhone 或 iPad 的“系统设置 -> 蓝牙”中，连接您的无线手柄（如 PS5、Xbox 手柄等）。连接成功后，iEmulator 会自动识别并适配手柄操作，手感直接拉满。
2. **大屏沉浸投屏**：通过系统顶部的下拉菜单选择“屏幕镜像”，将画面投屏到 Apple TV、iMac、MacBook 等苹果设备上。  
   > 💡 **特别注意**：iEmulator 专属优化了投屏体验！屏幕镜像投射的**仅仅是纯净的游戏画面**，而不是带有虚拟按键的应用界面，带给您真正的沉浸式大屏体验。
3. **原生大屏游玩**：如果您使用的是大屏幕 iPad，无需投屏，直接搭配无线手柄即可完美享受大屏游戏的乐趣。
